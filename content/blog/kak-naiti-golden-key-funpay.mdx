Golden Key — это авторизационный токен FunPay, без которого невозможно подключить ни один инструмент автоматизации. Если вы здесь, значит столкнулись с полем «введите Golden Key» и не понимаете где его взять. Этот гайд закрывает вопрос за 3 минуты.

## Что такое Golden Key и зачем он нужен

Golden Key — это cookie-токен сессии вашего аккаунта на funpay.com. Его формат: строка из ~32 символов (буквы и цифры). FunPay использует его для идентификации входящих запросов вместо логина и пароля.

Когда вы подключаете FunPay Cloud или любой другой сервис автоматизации — он использует ваш Golden Key чтобы действовать от имени вашего аккаунта: отвечать на сообщения, поднимать лоты, обрабатывать заказы.

> Подробнее о том, что такое Golden Key и зачем он нужен — в [отдельной статье о Golden Key FunPay](/blog/chto-takoe-golden-key-funpay).

## Где найти Golden Key: инструкция по браузерам

Golden Key хранится в куках вашего браузера. Его нужно скопировать оттуда вручную — FunPay не показывает его в настройках аккаунта.

### Google Chrome

1. Откройте [funpay.com](https://funpay.com) и убедитесь что вы авторизованы
2. Нажмите **F12** (или правая кнопка мыши → «Просмотр кода»)
3. Откройте вкладку **Application** (Приложение)
4. В левой панели: **Storage → Cookies → https://funpay.com**
5. В таблице найдите строку с именем **`golden_key`**
6. Значение в колонке **Value** — это и есть ваш Golden Key
7. Скопируйте его (двойной клик → Ctrl+C)

### Mozilla Firefox

1. Откройте [funpay.com](https://funpay.com) авторизованным
2. Нажмите **F12** → вкладка **Хранилище** (Storage)
3. В левой панели: **Куки → https://funpay.com**
4. Найдите строку **`golden_key`**
5. Скопируйте значение из правой колонки

### Safari (macOS)

1. Откройте **Safari → Настройки → Дополнения** → включите «Показывать меню Разработка»
2. Откройте [funpay.com](https://funpay.com) авторизованным
3. **Разработка → Показать Web Inspector** (или Opt+Cmd+I)
4. Вкладка **Storage → Cookies → funpay.com**
5. Строка **`golden_key`** — скопируйте значение

### Через расширение EditThisCookie (быстрый способ)

Если не хотите лезть в DevTools:
1. Установите расширение [EditThisCookie](https://chrome.google.com/webstore/detail/editthiscookie) для Chrome
2. Откройте funpay.com авторизованным
3. Нажмите на иконку расширения
4. Найдите `golden_key` в списке кук
5. Скопируйте значение

## Как вставить Golden Key в FunPay Cloud

1. Зайдите в [FunPay Cloud](https://funpay.cloud) → раздел **Аккаунты**
2. Нажмите **Добавить аккаунт**
3. Вставьте скопированный Golden Key в поле
4. Нажмите **Подключить**

Система проверит ключ и покажет имя вашего FunPay-аккаунта. Если всё верно — аккаунт активируется и автоматизация заработает.

## Сколько действует Golden Key

Golden Key действует пока вы **не выйдете из аккаунта FunPay** через кнопку «Выход». При выходе токен инвалидируется и нужно будет получить новый.

Срок жизни активной сессии — около **30 дней** с последнего использования. Если вы регулярно используете FunPay, ключ будет действовать постоянно.

**Что делать если ключ перестал работать:**
- Войдите на funpay.com снова
- Повторите инструкцию выше — получите новый Golden Key
- Обновите его в настройках аккаунта в FunPay Cloud (Аккаунты → Редактировать)

## Безопасность Golden Key

Golden Key — это фактически пароль от вашего аккаунта. Соблюдайте несколько правил:

| Что делать | Что НЕ делать |
|-----------|---------------|
| Вводить только в доверенные сервисы | Давать его незнакомым людям |
| Использовать только официальный FunPay Cloud | Вставлять в скрипты из интернета |
| Обновить ключ если он скомпрометирован | Хранить в открытых текстовых файлах |
| Выйти из аккаунта FunPay если нужно инвалидировать | Игнорировать подозрительную активность |

Если вы случайно поделились Golden Key — немедленно выйдите из аккаунта FunPay. Это инвалидирует текущий токен.

## Частые ошибки при вводе Golden Key

### «Неверный Golden Key» или «Ключ не найден»

- Убедитесь что скопировали **полное значение** без пробелов в начале и конце
- Проверьте что вы **авторизованы на funpay.com** именно под тем аккаунтом, который подключаете
- Попробуйте скопировать ключ снова — иногда первый раз копируется неполностью

### Поле `golden_key` в куках не отображается

- Убедитесь что вы находитесь именно на **https://funpay.com** (не на другой странице)
- Попробуйте обновить страницу (F5) и снова открыть DevTools
- Проверьте что вы смотрите правильный домен в списке кук — иногда нужно раскрыть `funpay.com`

### Аккаунт подключается, но автоматизация не работает

- Убедитесь что на вашем тарифе FunPay Cloud включена нужная функция
- Проверьте раздел **Логи** — там будут сообщения о причинах

## FAQ

### Можно ли использовать один Golden Key на нескольких сервисах?

Технически — да. Но это небезопасно: при утечке один токен откроет доступ везде. Рекомендуем использовать Golden Key только в одном инструменте — FunPay Cloud.

### Нужно ли обновлять Golden Key при смене пароля FunPay?

Да. Смена пароля инвалидирует текущие сессии, включая Golden Key. После смены пароля войдите заново на FunPay и получите новый ключ.

### Golden Key и пароль FunPay — это одно и то же?

Нет. Пароль — это то что вы вводите при входе. Golden Key — токен сессии, генерируется автоматически. Его нельзя задать вручную.

### Что будет с автоматизацией если Golden Key истечёт?

FunPay Cloud отправит уведомление в Telegram и приостановит работу аккаунта. Нужно будет ввести новый ключ в настройках.

### Можно ли получить Golden Key без входа через браузер?

Нет стандартного способа. FunPay не предоставляет API для получения токенов. Только через куки браузера после авторизации.
